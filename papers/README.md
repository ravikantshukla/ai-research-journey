# Papers

One note per paper, named `YYYY-short-title.md`:

- `YYYY` is the year the paper was published (not the year I read it).
- `short-title` is 2–5 lowercase words from the title, joined by hyphens.

Examples: `2017-attention-is-all-you-need.md`, `2022-toy-models-of-superposition.md`.

Start each note from [`templates/paper-notes.md`](../templates/paper-notes.md).
